# 📚 FullstackOpen

Ejercicios del curso [FullstackOpen](https://fullstackopen.com/) de la Universidad de Helsinki (React, Node.js, GraphQL, TypeScript...).

## Progreso

| Parte | Contenido | Estado |
|---|---|---|
| 0 | Fundamentos de apps web: HTTP, SPA, diagramas de interacción | ✅ Diagramas (`.mmd`) |
| 1 + | React, states, hooks... | 🔜 En curso |

Los diagramas de la parte 0 están en formato [Mermaid](https://mermaid.js.org/) — se puede previsualizar en GitHub directamente.

## Nota

Este repo de trabajo tendrá los ejercicios por parte. La meta es complementar la certificación de Back-end y APIs de freeCodeCamp con este curso.
